# W22｜模拟一薄弱点回补

> 周期：2027-04-19 至 2027-04-25 · 阶段：考前冲刺 · 优先级：按诊断结果 · 投入：12小时（10–15小时弹性）

## 本周目标
- [ ] 根据模拟一数据优先回补P0/P1，再补P2/P3。
- [ ] 对模拟错题进行变式训练，不只记忆原题答案。
- [ ] 案例专项聚焦最弱题型，强化题干证据和方案权衡。
- [ ] 论文素材查漏，完善真实项目职责、指标来源和关键决策。

## 综合知识（4h）
按模拟一错题TOP20回到知识点原理，完成变式题；P0/P1错题必须复测，P2/P3按官方大纲覆盖状态安排。

## 案例分析（4h）
选择最弱的两个专题各完成一题限时训练。答案至少写明一个备选方案及取舍理由，避免只罗列技术名词。

## 论文（2h）
核验素材证据，修订架构图和决策链。准备至少两个可迁移主题提纲，但不背诵与题目无关的固定套文。
