# 24 周学习计划与进度管理

本目录按《系统架构设计师知识点重要程度汇总》和官方考试大纲重排，目标是**先攻高权重架构能力，再补全大纲，最后用真题与模拟检验**。计划周期：2026-11-23 至 2027-05-09（24周）；每周按12小时设计，可在10–15小时弹性调整。

## 优先级

- **P0 最高**：软件架构设计、软件工程、架构评估与质量属性、Web应用架构、嵌入式系统架构。
- **P1 高**：信息安全与安全架构、数据库系统、专业英语、UML/DFD/ER/SysML、分布式系统与微服务、云原生与大数据。
- **P2 中**：系统工程与信息系统基础、计算机网络、操作系统核心算法、法律法规与标准化、软件可靠性、架构演化维护。
- **P3 低**：数学与经济管理、计算机组成原理基础、计算机性能基础、部分未来信息技术。

优先级是备考资源分配建议，不代表官方固定分值或逐年命题比例。官方大纲是覆盖边界，P2/P3 仍须完成最低限度学习与查漏。

## 六阶段路线

| 阶段 | 周次 | 核心任务 |
|---|---|---|
| 架构核心突破 | W01–W04 | 架构概念/4+1、架构风格、ABSD/DSSA、质量属性与ATAM/SAAM/CBAM |
| 软件工程与建模 | W05–W08 | 软件过程、需求工程、UML/建模、数据库基础 |
| 高频案例专题 | W09–W12 | Web、嵌入式、网络、数据库与数据架构 |
| 技术专题与全纲覆盖 | W13–W16 | 安全、分布式/SOA/微服务、云原生/大数据、可靠性/法规/英语/数学/演化 |
| 真题强化 | W17–W20 | P0真题、Web/嵌入式案例、全大纲查漏、综合模拟 |
| 考前冲刺 | W21–W24 | 两次模拟、薄弱点回补、限时论文与机考节奏 |

## 每周投入（12小时）

| 模块 | 时间 | 执行标准 |
|---|---:|---|
| 综合知识 | 4h | 对应考纲专题学习、选择题、错题回归 |
| 案例分析 | 4h | 至少2道独立作答，按需求—约束—备选—决策—质量属性复盘 |
| 论文 | 2h | 项目素材、架构图、提纲或正文段落；逐步过渡到限时全文 |
| 错题间隔复习 | 1h | 当天/次日/第3天/第7天主动回忆与重做 |
| 周复盘 | 1h | 统计正确率、案例得分点、论文产出，调整下周 |

10小时周优先保留三科核心训练和复盘；15小时周增加当周最低正确率科目、案例变式和论文限时写作。不得把P0周误解为其他科目完全停学。

## 统一验收规则

每周至少留下：知识结构/概念卡片、综合知识题量与正确率、2道案例的独立答案与订正、论文/项目素材、错题记录、3个薄弱点和补救动作。真题训练注明年份与来源；原创练习标注为练习题，不伪称真题。论文素材优先真实经历；模拟项目必须显式标注模拟，不得虚构个人职责或效果数据。
