# W18｜Web与嵌入式架构真题/高仿题专项

> 周期：2027-03-22 至 2027-03-28  
> 阶段：真题强化  
> 优先级：P0  
> 建议投入：12小时（可在10–15小时内调整）

## 本周定位与目标

**知识主线：** Web与嵌入式架构真题/高仿题专项。

**本周训练：** 完成至少4道Web/嵌入式案例；复盘得分点覆盖率；各形成一张架构图和一页选型矩阵。

- [ ] 综合知识：完成本周专题学习，至少完成40道对应练习题；P0主题额外做错题变式。
- [ ] 案例分析：至少完成2道独立限时题，逐项标注得分点、遗漏点与依据。
- [ ] 论文：完成本周指定素材或段落，形成可复用的架构决策论证。
- [ ] 错题：完成当天、次日、第3天、第7天间隔复习，更新错题索引。
- [ ] 复盘：记录三科数据、3个薄弱点及下一周补救动作。

## 综合知识（4小时）

1. 对照[官方考试大纲](../01_官方大纲与考试政策/系统架构设计师考试大纲.md)圈定本周范围，优先学习P0/P1知识点。
2. 以原理、适用条件、优缺点、易混概念和典型计算/图表为笔记结构，不抄长段教材。
3. 完成40–60道专题选择题；每道错题标注考纲条目、错因和复习日期。
4. 周末闭卷复述核心框架，目标是能解释“为什么”，而非只背术语。

## 案例分析（4小时）

**本周案例主题：** Web和嵌入式案例限时训练，比较方案并说明边界条件。

按五步法作答：①识别业务需求和质量属性；②提取题干约束与现状证据；③比较至少两个备选方案；④给出选择及适用条件；⑤说明对性能、可用性、安全、可修改性等的影响及新增风险。每道题限时完成后再对照参考答案订正。

案例库入口：[03_案例分析](../03_案例分析/README.md)。题目若来自历年真题，记录年份、题号和来源；教学自编题明确标注原创练习。

## 论文与项目素材（2小时）

**本周交付：** 完成Web或嵌入式主题论文提纲及一段正文。

围绕“项目背景/约束—问题与质量属性—备选方案—架构决策—实施验证—效果与不足”组织素材。优先采用真实项目并明确本人职责；若无对应经历，可用模拟案例训练，但必须标注“模拟项目”，不可把模拟数据、职责或成果写成真实经历。

论文资料入口：[04_论文](../04_论文/README.md)。
