# W20｜综合模拟与阶段复盘

> 周期：2027-04-05 至 2027-04-11 · 阶段：真题强化 · 优先级：全级别 · 投入：12小时（10–15小时弹性）

## 本周目标
- [ ] 完成一套综合知识模拟与一套完整案例模拟，严格计时。
- [ ] 完成至少一篇完整论文初稿，包含背景、本人职责、架构设计、关键决策、实施效果和不足。
- [ ] 形成错题TOP20，按P0/P1/P2/P3和错因分类。
- [ ] 统计三科耗时、正确率/得分点覆盖与主要失分原因。

## 综合知识（4h）
模拟一套综合知识试卷，按考纲映射错题；错误区分知识盲区、概念混淆、计算失误和审题失误。回到[02_综合知识](../02_综合知识/README.md)补齐根因。

## 案例分析（4h）
完成完整案例模拟，按考试节奏分配时间。每题按“需求—约束—备选—决策—质量属性”复盘，写出遗漏得分点和题干依据。题库入口：[03_案例分析](../03_案例分析/README.md)。

## 论文（2h）
限时完成一篇完整论文初稿。检查题目响应度、架构决策逻辑、个人职责真实性、指标证据和段落结构；模拟项目必须明确标注。
