# W23｜模拟考试二与论文限时

> 周期：2027-04-26 至 2027-05-02 · 阶段：考前冲刺 · 优先级：全级别 · 投入：12小时（10–15小时弹性）

## 本周目标
- [ ] 完成第二次完整计时模拟，检验知识稳定性和答题节奏。
- [ ] 与模拟一对比正确率、案例得分点覆盖、论文完成度和时间分配。
- [ ] 完成一篇限时论文或对上周全文进行二次限时重写。
- [ ] 确认最后一周只回顾高价值知识，不再开启大规模新专题。

## 综合知识（4h）
完成整卷或等量高质量模拟，重点观察P0/P1正确率是否稳定；P2/P3仅处理反复出现的错题和未覆盖项。

## 案例分析（4h）
完成完整案例计时。按题干证据检查架构方案是否可行、约束是否响应、质量属性权衡是否完整。

## 论文（2h）
限时全文训练，重点检查审题响应度、架构决策论证、段落衔接、真实性和效果证据。

## 验收
| 模块 | 时间 | 输出 |
|---|---:|---|
| 综合知识 | 4h | 第二次模拟卷与分专题统计 |
| 案例 | 4h | 完整案例模拟与复盘 |
| 论文 | 2h | 限时论文全文 |
| 间隔复习 | 1h | 最终高价值错题回测 |
| 复盘 | 1h | 两次模拟对比表 |
- [ ] 对比两次模拟数据并解释提升/下降原因。
- [ ] 论文在限定时间内完成，模拟经历与真实经历边界清晰。
- [ ] 最后一周复习清单不超过个人可执行范围。
