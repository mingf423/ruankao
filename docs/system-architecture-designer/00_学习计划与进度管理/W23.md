# W23｜模拟考试二

> 目标：2027 年上半年系统架构设计师考试；建议投入 10–15 小时，按官方考试日期调整。

> 概览图：[考试全景总览](../01_官方大纲与考试政策/00_考试全景总览.md)。

## 本周目标
- [ ] 完成第二轮全真模拟，检验时间分配、知识稳定性和答题表达。
- [ ] 完成综合知识错题回顾与重点专题练习。
- [ ] 完成至少 1 次案例限时训练：全真案例计时。
- [ ] 完成论文训练：论文模拟与自评。
- [ ] 整理考前风险与待确认事项。

## 每日安排
| 时间 | 任务 | 输出 |
|---|---|---|
| 周一 1.5h | 回顾高频知识与错题 | 高频考点清单 |
| 周二 2h | 案例限时训练：全真案例计时 | 答案与得分点复盘 |
| 周三 1.5h | 综合知识专题练习 | 错题回补记录 |
| 周四 2h | 论文写作：论文模拟与自评 | 限时稿/提纲 |
| 周五 1h | 复习标准规范、易混概念 | 考前检查表 |
| 周六 3h | 模拟考试或专项训练 | 模拟成绩与复盘 |
| 周日 1h | 周复盘与状态调整 | 最终薄弱点清单 |

## 本周验收
- [ ] 完成模拟/专项训练并记录用时和失分点。
- [ ] 对薄弱点形成可执行的最后复习动作。
- [ ] 论文结构完整，架构决策和质量属性论证明确。
- [ ] 检查考试通知、准考证及机考要求，以官方信息为准。
