# W19｜全大纲查漏

> 周期：2027-03-29 至 2027-04-04  
> 阶段：真题强化  
> 优先级：P1/P2/P3  
> 建议投入：12小时（10–15小时弹性调整）

## 本周目标

- [ ] 逐项核对官方考试大纲，重点查漏网络、操作系统核心算法、数据库、安全、法规标准、专业英语、数学、可靠性、架构演化和未来技术。
- [ ] 每个知识点标记“已掌握/需复习/未学习”，不得将低优先级理解为免考。
- [ ] 完成至少40道混合选择题，并对薄弱条目补充概念卡片。
- [ ] 完成2道跨专题限时案例，按需求、约束、备选、决策、质量属性复盘。
- [ ] 校验真实项目素材、职责边界、指标来源和架构决策证据。

## 综合知识（4小时）

以官方大纲逐条审计为主，P2/P3至少掌握核心概念、典型应用和常见考法。建立覆盖矩阵，标注资料位置、最近复习时间和掌握状态。对不熟悉条目回到[02_综合知识](../02_综合知识/README.md)。

## 案例分析（4小时）

完成2道跨专题案例，训练识别跨层约束与技术依赖。答案必须有题干证据，不能只堆砌技术名词。复盘至少包含一个被排除方案及排除理由。

案例入口：[03_案例分析](../03_案例分析/README.md)。

## 论文（2小时）

整理论文素材库：项目背景、本人职责、系统边界、关键架构决策、实施验证和可核验效果。标记缺证据的陈述；模拟案例必须明确标注。

- [ ] 每个未掌握条目都有补救日期。
