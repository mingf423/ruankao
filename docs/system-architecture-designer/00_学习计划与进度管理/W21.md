# W21｜模拟考试一

> 周期：2027-04-12 至 2027-04-18 · 阶段：考前冲刺 · 优先级：全级别 · 投入：12小时（10–15小时弹性）

## 本周目标
- [ ] 完成第一次全真模拟：综合知识、案例分析和论文/对应考试科目训练。
- [ ] 严格计时，模拟机考环境与键盘输入节奏。
- [ ] 形成按影响程度排序的薄弱点清单，并为每项指定补救动作。
- [ ] 记录答题顺序、时间分配和未完成原因。

## 综合知识（4h）
完成整卷计时，统计总正确率与分专题正确率。错误映射回官方大纲；优先修复P0/P1知识盲区，再处理高频P2/P3错题。

## 案例分析（4h）
全真计时作答。每道题标记需求、约束、备选、决策、质量属性证据，统计未答完/表达不清/技术选型无依据等失分类型。

## 论文（2h）
限时完成论文，练习审题、提纲、正文输入和结尾检查。核查个人职责和项目数据可证实。
