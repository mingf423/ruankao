# W24｜考前收口与状态管理

> 周期：2027-05-03 至 2027-05-09 · 阶段：考前冲刺 · 优先级：全级别 · 投入：10–12小时，按官方考试日期调整

## 本周目标
- [ ] 完成官方大纲最终覆盖检查，确认无未标记条目。
- [ ] 回忆P0架构框架、质量属性场景、架构评估方法和高频案例决策。
- [ ] 回测高价值错题、公式、标准法规与专业英语术语。
- [ ] 复盘案例五步法、论文结构和时间分配。
- [ ] 保证睡眠和稳定状态，不熬夜补进度。

## 综合知识（4h）
以概念卡片、公式、易混点和高价值错题为主。P3内容只做基础回忆，不再进行低收益的广泛拓展。

## 案例分析（3–4h）
复述五步法，挑选1–2道代表性案例做结构化作答。检查答案是否引用题干证据、是否给出备选和权衡。

## 论文（1–2h）
回顾真实项目事实、职责边界、架构图和论证素材；按题目关键词快速列提纲，不背诵固定套文。

## 最终检查
- [ ] 官方考试通知、准考证、考试时间地点/机考要求已自行核对。
- [ ] 官方大纲覆盖表无未标记条目。
- [ ] P0/P1关键框架可闭卷复述。
- [ ] 高价值错题已完成最后回测。
- [ ] 论文项目事实、本人职责与数据来源可解释。
- [ ] 考试用品、设备/交通安排和作息已确认。
