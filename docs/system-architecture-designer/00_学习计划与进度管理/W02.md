# W02｜操作系统

> 周期：2026-11-30 至 2026-12-06  
> 本周主题：操作系统  
> 建议投入：10–15 小时（基准 12 小时）

## 本周目标

- [ ] 对照官方大纲理解本周主题的核心概念、原理、适用条件与常见考法。
- [ ] 完成综合知识专题学习和至少 60–100 道对应练习题（冲刺周按模拟任务调整）。
- [ ] 完成至少 2 道案例题或一组限时案例训练。
- [ ] 形成一项论文/模拟项目输出：论文四段式结构。
- [ ] 更新错题与薄弱点记录，并完成周复盘。

## 学习内容

- 知识主线：操作系统。
- 深入笔记：[操作系统知识文档](../02_综合知识/操作系统与网络/操作系统.md)。
- 概览图：[综合知识概览图 · 图 1 计算机系统](../01_官方大纲与考试政策/01_综合知识大纲脑图.md)。
- 复习时同时检查该主题与计算机系统、软件架构及质量属性之间的联系，不只记忆定义。

## 案例分析训练

本周案例重点：进程、线程、并发与资源管理。

按“识别需求 → 识别约束 → 比较备选方案 → 给出决策及理由 → 论证质量属性效果”组织答案。记录题目来源、题干关键条件、得分点、遗漏点和改进动作。

## 论文与模拟项目

本周输出：论文四段式结构。优先使用本人真实参与的项目经历；若使用贯穿备考的电商架构升级项目，必须标注为模拟案例，不虚构个人职责、项目规模或效果数据。
