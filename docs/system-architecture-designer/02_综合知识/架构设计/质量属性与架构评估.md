# 质量属性与架构评估

## 核心知识框架
性能、可用性、安全性、可修改性、互操作性、可测试性、可部署性；质量属性场景；质量属性冲突与权衡；敏感点、权衡点、风险；ATAM 等评估方法。

## 质量属性场景模板
| 要素 | 说明 |
|---|---|
| 刺激源 | 谁或什么触发 |
| 刺激 | 发生什么事件 |
| 环境 | 正常、峰值、故障等 |
| 制品 | 系统、组件或接口 |
| 响应 | 系统采取的行为 |
| 响应度量 | 可验证的时间、比例、容量或恢复指标 |

## 案例答题框架
明确目标与优先级 → 场景量化 → 识别架构决策 → 分析敏感点/风险/冲突 → 提出改进与验证指标。
