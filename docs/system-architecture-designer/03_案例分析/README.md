# 案例分析

## 入门推荐

刚接触案例分析题型时，建议先精读并对照练习：

- [单机订单系统性能优化-教学案例](性能与硬件约束/单机订单系统性能优化-教学案例.md)

该原创教学案例演示证据驱动的瓶颈诊断、方案对比、缓存数据边界、应用扩展概念及质量属性权衡；不是历年真题原文。

## 案例审校要求

- 区分题干事实、假设和待验证信息。
- 性能问题先诊断后选型；数据库场景按需检查 SQL、索引、执行计划、锁、事务、连接池和 I/O 指标。
- 明确方案适用条件、收益、风险和运维代价。
- 交易关键数据须说明权威数据源、一致性与并发控制。
- 题型/评分形式以当次官方考试通知为准。
