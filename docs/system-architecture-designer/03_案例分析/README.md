## 入门推荐

刚接触案例分析题型时，建议按本周计划选做，不要一次混做所有教学案例。

- W01 指定：[架构驱动力与质量属性场景识别](架构基础与视图/架构驱动力与质量属性场景识别-教学案例.md)、[从需求推导架构视图](架构基础与视图/从需求推导架构视图-教学案例.md)。两篇是同一虚构背景，先识别驱动力再画视图。
- 性能诊断方法：[单机订单系统性能优化](性能与硬件约束/单机订单系统性能优化-教学案例.md)。它演示证据驱动的瓶颈分析，不替代 W01 的视图训练。

这些都是原创教学案例，不是历年真题原文。

## 案例审校要求

- 区分题干事实、假设和待验证信息。
- 性能问题先诊断后选型；数据库场景按需检查 SQL、索引、执行计划、锁、事务、连接池和 I/O 指标。
- 明确方案适用条件、收益、风险和运维代价。
- 交易关键数据须说明权威数据源、一致性与并发控制。
- 题型/评分形式以当次官方考试通知为准。
