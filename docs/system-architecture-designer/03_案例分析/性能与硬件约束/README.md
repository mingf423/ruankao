# 性能与硬件约束

本目录收录性能分析、容量规划、硬件约束和系统扩展相关案例。答题与方案设计遵循“先识别证据与瓶颈，再比较方案，最后论证质量属性”的原则。

## 案例索引

- [单机订单系统性能优化（教学案例）](单机订单系统性能优化-教学案例.md)：练习数据库性能诊断、SQL/索引/事务分析、缓存边界、应用水平扩展、读写分离和质量属性权衡。

## 分析检查要点

- 区分题干已知事实、合理假设和待验证信息。
- 结合慢 SQL、执行计划、索引、锁等待、事务时长、连接池、CPU、IOPS、磁盘延迟等证据定位瓶颈。
- 不把缓存、垂直扩容、读写分离或分库分表当作万能方案。
- 区分展示数据缓存与库存、余额、支付状态等交易关键数据。
- 说明应用多实例、负载均衡、无状态化、复制延迟和故障切换等必要条件。
