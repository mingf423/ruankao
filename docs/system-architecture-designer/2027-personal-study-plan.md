# 2027 年上半年系统架构设计师备考计划（优先级驱动版）

> 计划周期：2026-11-23 至 2027-05-09，共24周；每周10–15小时，以12小时为基准。2027年考试日期、批次、报名及机考要求以官方通知为准；若日期变化，整体平移或压缩冲刺阶段。

## 1. 备考策略与优先级

本计划依据《系统架构设计师知识点重要程度汇总》和官方考试大纲重排：先集中攻克架构设计能力，再强化软件工程、建模和典型案例，随后覆盖技术专题及全大纲，最后用真题、模拟和限时论文检验。重要程度是个人备考资源分配建议，不代表官方固定分值或逐年命题比例；官方大纲仍是完整覆盖边界。

| 优先级 | 知识范围 | 训练策略 |
|---|---|---|
| P0 最高 | 软件架构设计、软件工程、架构评估与质量属性、Web应用架构、嵌入式系统架构 | 多轮学习、案例优先、论文重点素材、真题反复训练 |
| P1 高 | 信息安全与安全架构、数据库系统、专业英语、UML/DFD/ER/SysML、分布式系统与微服务、云原生与大数据 | 专题学习、案例专项、错题间隔复习 |
| P2 中 | 系统工程与信息系统基础、计算机网络、操作系统核心算法、法律法规与标准化、软件可靠性、架构演化维护 | 完成大纲覆盖、典型题训练、查漏补缺 |
| P3 低 | 数学与经济管理、计算机组成原理基础、计算机性能基础、部分未来信息技术 | 掌握概念/公式与基础考法，避免投入失衡 |

| 高频案例专题 | W09–W12 | Web、嵌入式、网络、数据库与数据架构 | Web/嵌入式专项案例、数据架构比较 |
| 技术专题与全纲覆盖 | W13–W16 | 安全、分布式/SOA/微服务、云原生/大数据、可靠性/法规/英语/数学/演化 | P1专项成果、官方大纲逐项覆盖表 |

## 3. 每周时间分配（12小时基准）

| 模块 | 时间 | 训练内容 |
|---|---:|---|
| 综合知识 | 4h | 对照大纲学习、专题题目、错题回归 |
| 案例分析 | 4h | 每周至少2道独立限时作答，按需求—约束—备选—决策—质量属性复盘 |
| 论文写作 | 2h | 项目素材、架构图、提纲、正文段落；后期转为限时全文 |
| 错题间隔复习 | 1h | 当天、次日、第3天、第7天主动回忆和重做 |
| 周复盘 | 1h | 统计正确率、案例得分点覆盖、论文产出和补救动作 |

每周10小时：优先保留三科训练和复盘，减少拓展阅读。每周15小时：额外时间投向当周正确率最低科目、P0案例变式和论文限时训练。

## 4. 案例与论文统一方法

### 案例五步法
1. 识别业务需求和关键质量属性；
2. 提取题干约束、现状证据和风险；
3. 比较至少两个可行方案；
4. 给出决策及适用条件；
5. 论证性能、可用性、安全性、可修改性等收益和新增代价。

### 论文四段式
1. 项目背景、系统边界、规模、约束与本人真实职责；
2. 总体架构、架构风格、关键技术选型及理由；
3. 核心问题、备选方案、架构决策、实施过程和质量属性权衡；
4. 可核验效果、问题不足和改进方向。

优先使用真实参与项目。模拟项目必须明确标注“模拟项目”，不得虚构本人职责、规模、指标或已落地效果。论文素材入口：[04_论文](04_论文/README.md)。

## 5. 间隔复习与进度管理

- 当天：闭卷写出3–5个概念、原理或公式。
- 次日：口头复述关键框架。
- 第3天：重做错题，仍错则标记重点。
- 第7天：闭卷小测并更新掌握状态。

每周记录实际学习时长、综合知识题量/正确率、案例完成数/得分点覆盖、论文交付物、3个薄弱点及补救动作。错题统一进入[05_错题与薄弱点](05_错题与薄弱点/README.md)。
